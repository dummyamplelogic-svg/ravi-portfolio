RAVI TEJA JAVANGULA - PORTFOLIO

HOW TO VIEW
1. Extract Ravi-Portfolio.zip.
2. Open the Ravi-Portfolio folder in Visual Studio Code.
3. Open index.html in your browser, or use the VS Code Live Server extension.
4. Keep the images and assets folders alongside index.html.

BEFORE PUBLISHING
- Review the employment dates and overlapping roles in the uploaded resume.
- Add a PDF resume if you want a PDF download. The supplied resume is included as DOCX.
- Confirm all content is accurate and update anything that has changed.

The site uses Google Fonts when internet access is available. It otherwise falls back to system fonts.
